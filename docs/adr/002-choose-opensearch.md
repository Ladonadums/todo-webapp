# 002. Выбрать OpenSearch вместо Elasticsearch

## Контекст
Для реализации полнотекстового поиска по задачам нужно выбрать движок: Elasticsearch или его форк OpenSearch.

## Варианты
- **Elasticsearch**: оригинальный продукт, но с ограничениями лицензии (SSPL).
- **OpenSearch**: open-source форк от AWS, полностью бесплатный, активно развивается.

## Решение
Выбран **OpenSearch**, потому что:
- Полностью открытая лицензия (Apache 2.0),
- Совместим с Elasticsearch API,
- Подходит для учебного и коммерческого использования без юридических рисков.

## Последствия
- Небольшая разница в конфигурации по сравнению с Elasticsearch,
- Полная свобода в использовании и модификации.
