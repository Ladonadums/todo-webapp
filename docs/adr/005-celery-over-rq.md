# 005. Использовать Celery вместо RQ для фоновых задач

## Контекст
Нужен инструмент для асинхронной индексации задач в OpenSearch. Варианты: Celery, RQ, Kafka.

## Варианты
- **RQ**: простой, Python-only, но ограничен в функционале.
- **Celery**: мощный, поддерживает retry, scheduling, multiple brokers.
- **Kafka**: избыточен для MVP.

## Решение
Выбран **Celery с Redis в качестве брокера**, потому что:
- Поддерживает retry и idempotency out of the box,
- Хорошо интегрируется с FastAPI и Django,
- Достаточно гибкий для расширения.

## Последствия
- Немного больше зависимостей,
- Готовность к сложным сценариям (периодические задачи, rate limiting).
