# 004. Проверять JWT в API Gateway, а не в каждом сервисе

## Контекст
Где выполнять валидацию JWT: в каждом сервисе или централизованно?

## Варианты
- **В каждом сервисе**: дублирование кода, сложнее управлять ключами.
- **В API Gateway**: единая точка проверки, меньше дублирования.

## Решение
Проверка JWT выполняется **в API Gateway**, потому что:
- Это соответствует best practices микросервисной архитектуры,
- Упрощает сервисы — они получают только валидные запросы,
- Централизует безопасность.

## Последствия
- Все защищённые эндпоинты должны проходить через Gateway,
- Сервисы доверяют входящим данным (требуется внутренняя сеть).
